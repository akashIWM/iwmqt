04 — Phase 2

Company Account as a real entity

Before today, "Company Account" was a role label on a user row — no entity record, and no way for anyone to create an account at all except self-service sign-up.

Companies table done

A company is now a first-class record: code, name, status. The organisation boundary the spec describes.

Create / suspend flow done

Super Admin creates a company and its first Company Account login in one step, with a one-time temporary password. Suspending a company blocks login for every user under it instantly — and reactivating is just as instant.

Admin-initiated account creation done

Previously impossible for any role. Company Account can now create RMS Admin / PM / Trader logins within its own entity only — enforced server-side, not just hidden in the UI.

Entity-scoped user list partial

A Company Account only sees its own entity's users. Order Book, Positions, Audit Log, and Kill Switch remain platform-wide — a scoped follow-up, not done yet.

06 — Phase 4

HFT-grade grid & WebSocket layer

Section 5's literal ask — "the GUI must feel instant" — implemented, not just aspired to.

Delta protocol done

Market data now streams only what changed, with a strict sequence number. A dropped message is detected and self-heals via a resync request — verified with a raw socket client.

Grid transactions done

Watchlist, Order Book, Net Positions, and Ban Script all update via row-level transactions instead of full re-renders.

CSV export & columns done

Every grid exports to CSV, and column order/width now survives a page reload.

Code-split by role done

Split one 1.5 MB shared bundle into five per-role chunks — RMS Admin and Company Account now load ~1.8 KB instead of the whole app.

Grouping partial

"Group by Symbol" ships as a Community-tier substitute. True OMS/Token grouping needs a paid AG Grid Enterprise licence — a decision for the business, not engineering.

Light theme default pending

Spec wants a light, low-repaint default for trading screens; all grids are still dark. Flagged, not started.
